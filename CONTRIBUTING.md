# Contributing to GuardMCP

Thank you for your interest in contributing to **GuardMCP**! We welcome community contributions to help make AI Model Context Protocol (MCP) ecosystems more secure and resilient.

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/raghav1924/guardmcp.git
   cd guardmcp
   ```

2. **Compile TypeScript:**
   ```bash
   npm run build
   # or watch mode
   npm run dev
   ```

3. **Run Unit Tests:**
   ```bash
   npm test
   ```

## Pull Request Guidelines

- Ensure all existing and new unit tests pass (`npm test`).
- Keep changes zero-dependency: utilize Node.js standard libraries (`node:fs`, `node:path`, `node:http`).
- Write meaningful, conventional commit messages (`feat:`, `fix:`, `docs:`, `test:`).
- Document new security rules in both `README.md` and `PRODUCT_BRIEF.md`.

## Code of Conduct

We are committed to providing a welcoming, inclusive, and harassment-free environment for everyone. Please be respectful and constructive in all discussions and reviews.
