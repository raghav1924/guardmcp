# GuardMCP Design System

Integrating the **29 Master Design Patterns**:
- **Cybercore (#24)**: High-density tactical telemetry readouts for AI tool inspection.
- **Dark Mode UI (#20)**: Deep obsidian canvas with neon status pills (Rose, Amber, Emerald).
- **Bento Grid (#12)**: Modular card grid grouping risk scores, server mounts, and tool permissions.
